# Formation IA & DevOps — 1 journée

Site statique de la formation « IA & DevOps » (NeoSoft), déployable sur Vercel.

## Déploiement Vercel

1. Pousser ce dépôt sur GitHub.
2. Sur https://vercel.com → **Add New… → Project** → importer le dépôt.
3. Framework Preset : **Other** (site statique, aucune configuration de build).
4. Deploy.

Site purement statique (HTML/CSS/JS) : pas de build, `vercel.json` active juste les URLs propres.
