Introduction à l'IA

Démystifier l'IA générative : ce qu'est un LLM, comment il « raisonne », pourquoi il se trompe avec aplomb, et comment choisir un assistant et un mode de déploiement.

🎯 Objectifs du module

  • Situer l'IA générative et les LLM dans la grande famille de l'IA.
  • Expliquer qu'un LLM est un générateur probabiliste de tokens, et en déduire ses limites.
  • Distinguer les familles d'assistants (chat, IDE, CLI, agent).
  • Choisir un mode de déploiement selon la sensibilité des données.
Démarrer par une question à main levée : « Qui a utilisé une IA cette semaine pour son travail ? Pour quoi faire ? » Noter 3-4 usages au tableau, on y reviendra en M5.

2De quoi est faite l'IA ? Les techniques d'apprentissage

La grande famille de l'IA

IA = IA symbolique (≈ 5 %) + Machine Learning (≈ 95 %).

  • IA symbolique : règles écrites par des humains (« si… alors… »), systèmes experts. Prévisible, mais ne s'adapte pas seule.
  • Machine Learning : la machine apprend des régularités à partir de données. C'est là-dessus que reposent le Deep Learning, les LLM et l'IA générative.

3Deep Learning et IA générative

Le Deep Learning : apprendre des représentations, couche par couche

Le Machine Learning classique demande à un humain de concevoir les bonnes caractéristiques (features) à partir des données brutes. Le Deep Learning s'en passe : un réseau de neurones artificiel, composé de nombreuses couches de « neurones » (de simples calculateurs : multiplication, somme, seuil), apprend lui-même les représentations utiles, du plus simple au plus abstrait.

🧠 Pourquoi « profond » ?

Beaucoup de couches empilées. Plus le réseau est profond, plus il peut représenter des notions abstraites — à condition d'avoir énormément de données et de puissance de calcul (GPU). C'est l'explosion des données + des GPU qui a fait décoller le deep learning (AlexNet, 2012).

⚙️ L'entraînement en une phrase

On montre des millions d'exemples ; à chaque passe, on mesure l'erreur, et on ajuste les poids des connexions (rétropropagation) pour la réduire. Rien d'« intelligent » : de la statistique à très grande échelle.

✨ L'IA générative

Un sous-ensemble du deep learning dont le modèle apprend la distribution des données pour en produire de nouvelles : texte et code (LLM), images (diffusion), audio… Elle génère là où les modèles classiques classifient ou prédisent une valeur.

À retenirDeep Learning = la technique (réseaux de neurones profonds). IA générative = le usage qui en est fait (produire du contenu nouveau). Un LLM est les deux à la fois : un réseau Transformer profond entraîné à générer du texte, token après token.

4Comment fonctionne un LLM

Un LLM ,Large Language Model, ne « sait » rien au sens humain : il prédit le morceau de texte suivant le plus probable compte tenu de tout ce qui précède, puis recommence, morceau après morceau.

🔤 Le token

Unité élémentaire de texte qu'un LLM utilise pour lire, traiter et générer du langage : un mot, un morceau de mot ou un signe. Avant de traiter une phrase, le modèle la découpe en petits morceaux appelés tokens.

  • Compréhension — le modèle transforme le texte en tokens pour pouvoir le traiter.
  • Génération — il prédit et génère une succession de tokens pour construire sa réponse.
  • Coût et limites — le nombre de tokens consommés influence le coût d'utilisation des API et la quantité de contexte traitable.

🎲 La température

Paramètre utilisé dans les LLM pour contrôler le degré d'aléatoire dans la génération des réponses.

  • Basse (0 à 0,3) — réponses plus prévisibles, constantes et précises. Ex. : générer un script Python de sauvegarde.
  • Moyenne (0,4 à 0,7) — équilibre entre cohérence et diversité. Ex. : expliquer le fonctionnement d'une architecture Kubernetes.
  • Élevée (0,8 à 1,5) — réponses plus variées, parfois surprenantes et moins prévisibles. Ex. : trouver des idées originales pour automatiser un processus DevOps.
À retenirUn LLM est un grand modèle de langage entraîné pour traiter le langage humain (Comprendre des questions, Générer du texte, Résumer des documents, Traduire des langues).

6Les familles d'assistants

💬

Chat web

Interface conversationnelle (ChatGPT, Claude.ai, Gemini, Le Chat, Copilot Chat…). Idéal pour explorer, expliquer, rédiger.

Limite : rien n'est versionné ni partagé avec l'équipe.

🧑‍💻

Assistant d'IDE

Complétion et chat dans l'éditeur (GitHub Copilot, Cursor, JetBrains AI, Continue…). Idéal pour écrire et refactorer.

⌨️

Agent en CLI

Agent de code au terminal (Claude Code, Codex CLI, Gemini CLI, Copilot CLI, Mistral Vibe…). Lit le dépôt, lance des commandes, scriptable.

🤖

Agent autonome

Boucle « observer → raisonner → agir » avec des outils (via MCP). Peut traiter une issue, ouvrir une PR, diagnostiquer un cluster.

Ce qui distingue les familles d'assistantsElles se différencient par leur fonctionnalité, leur domaine d'intervention et les tâches qu'elles sont capables de réaliser.

✅ Ce qu'il faut retenir

  • IA ⊃ ML ⊃ Deep Learning ⊃ IA générative ⊃ LLM : un LLM est un réseau de neurones profond entraîné sur d'immenses corpus pour générer du texte et du code.
  • Un LLM ne « sait » rien au sens humain : il prédit le token suivant le plus probable. Il produit du plausible, pas du vérifié.
  • Le token est son unité de base (compréhension, génération, coût et fenêtre de contexte) ; la température règle le degré d'aléatoire des réponses.
  • Limites clés et leurs parades : hallucination (contrôles déterministes, doc officielle), données datées (fournir le contexte à jour), fenêtre finie (filtrer l'essentiel), non‑déterminisme (jamais un LLM en gate bloquant), complaisance (questions neutres).
  • Quatre familles d'assistants, de la suggestion à l'action : chat web → IDE → CLI → agent autonome. Plus d'autonomie = plus de garde‑fous.
  • Le mode de déploiement se choisit d'abord selon la sensibilité des données.
